# Picture library

Every picture a pack can name with `"picture": "cat"` is listed here. Names are lowercase with hyphens, the word a pack author would type.

## Where the art comes from

Most pictures are from [Fluent UI Emoji](https://github.com/microsoft/fluentui-emoji) by Microsoft, used under the MIT licence. Starbook uses one of its styles for every picture, Flat (SVG) or 3D (PNG), as set in [`design.md`](design.md), from this exact commit: `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`. Each Fluent picture is `assets/pictures/<name>.svg` in the app.

> Copyright (c) Microsoft Corporation.
>
> Licensed under the MIT License (the full text is in the Fluent UI Emoji repository, file `LICENSE`).

The app ships the full licence text in `assets/licenses/fluentui-emoji.txt`.

Items marked `drawn` have no fair Fluent emoji. They are made for this project in the same flat style and are released under the MIT licence with the rest of Starbook.

If a pack needs a picture that is not in this list, use an emoji instead: `"picture": "emoji:🦚"`.

## How to read the tables

- **name**: what you type in a pack.
- **Fluent folder**: the folder name in the Fluent UI Emoji repository under `assets/`, exactly as written there, or `drawn`.
- **note**: `FLAG` marks a stand-in that a child might name differently. Fair matches carry a short remark or none. Skin-tone emoji (people, hands, body parts) always use the `Default` tone.
