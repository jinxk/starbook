# Stickers

Sticker awards name stickers from this list. The default sticker set is this table in order. Every sticker has a Fluent Emoji 3D still, `assets/stickers/<name>.png`. Where Google Noto has an animated version it is `assets/stickers/<name>.json` (Lottie); it plays when the sticker arrives and when it is tapped. A sticker with `none` shows its still with a wobble on tap.

- Noto Animated Emoji, Google, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Files from `https://fonts.gstatic.com/s/e/notoemoji/latest/<codepoint>/lottie.json`, not changed.
- Fluent Emoji 3D, Microsoft, MIT, commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc` (same as [`pictures.md`](pictures.md)), files from `assets/<folder>/3D/`.

The licence texts ship in `assets/licenses/`. `cat` uses the Noto cat face; Noto has no full-body cat. Noto has no animated elephant.
