# Stickers

Sticker awards name stickers from this list. Each sticker is an animated Google Noto emoji where one exists, and a Fluent Emoji 3D image otherwise (also used as the still frame).

- Noto Animated Emoji, Google, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Files from `https://fonts.gstatic.com/s/e/notoemoji/latest/<codepoint>/lottie.json`.
- Fluent Emoji 3D, Microsoft, MIT, commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc` (same as [`pictures.md`](pictures.md)).

The list grows as stickers are added; a name here always has both files in `assets/stickers/`.
